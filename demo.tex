以下为行内公式测试：\\
如图，线段 \(P_1 P_2\) 的端点 \(P_1\)，\(P_2\) 的坐标分别是$(x_1，y_1)$，$(x_2，y_2)$，
点 \(P\) 是直线 \(P_1 P_2\) 上异于 \(P_1\)，\(P_2\) 的点，当 \(\overrightarrow{P_1 P }=\lambda\overrightarrow{PP_2}\) 
($\lambda\neq 0$且 \(\lambda\neq 1\)) 时，\(\overrightarrow{OP} =\frac{1}{1 + \lambda} \overrightarrow{OP_1} + \frac{\lambda}{1 + \lambda} \overrightarrow{OP_2}\)，
点 \(P\) 的坐标是 \(\left(\frac{x_1 + \lambda x_2}{1 + \lambda} , \frac{y_1 + \lambda y_2}{1 + \lambda}\right)\)，
当 \(\lambda>0\) 时，点 \(P\) 在线段 \(P_1 P_2\) 上，称为内分点；当 \(\lambda<0\) 且 \(\lambda\neq -1\) 时，点 \(P\) 在线段 \(P_1 P_2\) 的延长线上，称为外分点。

\section{练习与解答*}
演示：
\begin{exercise}
    求极限 $\displaystyle \lim_{x\to 0} \frac{\sin 3x}{x}$.
\end{exercise}
\begin{answer}
    3
\end{answer}
\begin{explanation}
    利用重要极限，$\displaystyle \lim_{x\to 0} \frac{\sin 3x}{x}=3\lim_{x\to 0}\frac{\sin 3x}{3x}=3\times 1=3$.
\end{explanation}
